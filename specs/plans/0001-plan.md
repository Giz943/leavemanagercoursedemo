## Risks & open questions
**Ortam (R-13):** `dash scripts/doctor` → `0 fail, 1 warn` (check.conf'ta adım yok — beklenen);
profil sonucu henüz yok. Bu makine: **Node v26.7.0**, npm 12.0.2; nvm/fnm/volta yok, Homebrew var
(`node@24` 24.22.2 kurulabilir). `docs/conventions.md` ise **Node 24 LTS** diyor.

1. **Node sürümü.** Node release takvimine göre Node 26, Ekim 2026'da Active LTS oldu; Node 24
   Maintenance LTS'te. Seçtiğimiz tüm araçların `engines` alanı Node 26'yı destekliyor.
   **Önerim:** Node **26 LTS**'e geç (`.nvmrc` = 26, `engines` `>=26 <27`, `requires install`
   Node 26'yı kontrol eder), `docs/conventions.md`'yi güncelle. Gerekçe: zaten kurulu, kurs için en
   güncel LTS, ek araç kurulumu yok. Alternatif: `brew install node@24` ve dokümana sadık kal.
2. **Paket sürümleri dokümandan ileri gitmiş.** Bugünkü güncel kararlı: TypeScript 7.0, Vite 8,
   Vitest 5, ESLint 10, zod 4, React 19.3, Hono 4.13, Drizzle 0.45, better-sqlite3 13.
   typescript-eslint yalnızca `typescript <6.1` destekliyor.
   **Önerim:** TypeScript **5.9.3** (dokümana uygun, typescript-eslint ile uyumlu); diğerleri güncel
   major (Vite 8, Vitest 5, ESLint 10, zod 4); `docs/conventions.md` sürüm satırları buna göre
   güncellenir. TypeScript 7'ye geçiş, typescript-eslint desteklediğinde ayrı bir ADR.
3. **macOS `/bin/sh`** — `./scripts/check` parse edemiyor (Known traps). **Önerim:** bu build'de
   bütün kanıt `dash scripts/check` ile; CI (Linux) etkilenmiyor.
4. **better-sqlite3 native modülü** — Node 26 için hazır binary yoksa derleme gerekir (Xcode CLT).
   **Önerim:** adım 1'de kurulumla hemen sına; derleme başarısızsa R-13 ile dur, sessizce paket değiştirme.
5. **Yeni bağımlılıklar** (security.md: plan onayı yeterli; hepsi MIT/Apache-2.0/BSD/ISC):
   hono, @hono/node-server, drizzle-orm, better-sqlite3, zod, react, react-dom; geliştirme:
   typescript, vite, @vitejs/plugin-react, vitest, @vitest/coverage-v8, jsdom,
   @testing-library/react, eslint, typescript-eslint, eslint-plugin-react, eslint-plugin-react-hooks,
   prettier, concurrently, @types/*. **Önerim:** onayla; lisanslar adım 1'de `npm ls`/paket
   bilgisiyle teyit edilir.
6. **Seçici (Two speeds kural 4).** `test-unit [fast]`: `vitest run --exclude "**/*.int.test.ts"`;
   `test-integration`: `vitest run .int.test.` (dosya yolu filtresi). Aynı desen, biri hariç tutar,
   diğeri yalnızca onu çalıştırır. **Önerim:** adım 6'da sayıları doğrula (fast + int = toplam).
7. **AC-2 için veritabanı hatası** testte gerçek bir arıza üretmek yerine `DatabaseProbe` enjekte
   edilerek simüle edilir; HTTP kodu **503** (spec G5). **Önerim:** kabul — kapatılmış bir bağlantı
   (`db.close()` sonrası probe) ile ikinci bir gerçekçi test de eklenir.
8. **Geliştirme veritabanı** `data/dev.sqlite` (gitignore); testler yalnızca `:memory:`.
